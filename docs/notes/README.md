## 常用词

| 词 | 意思 |
|---|---|
| 网关（gateway） | 所有"改东西"的请求都要经过的检查点，决定直接执行还是扣住等验证 |
| `pending_mfa` | 操作被扣住、等人验证的状态 |
| digest | 由操作类型、参数、申请人算出的 16 位指纹，用来把批准绑在一笔具体的操作上 |
| 执行凭证（ExecutionGrant） | 执行器只认的"放行条"，只有网关能发 |
| fail closed | 看不懂、查不完的时候，按"危险"处理，而不是放行 |
| 召回率（recall） | 钓鱼邮件里被抓到的比例 |
| 误报率（FPR） | 正常邮件里被错标成钓鱼的比例 |
| 裁判（oracle） | 红队里判定"是否被攻破"的检查，只看结果 |
